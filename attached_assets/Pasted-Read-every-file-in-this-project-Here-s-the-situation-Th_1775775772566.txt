Summary of what's actually broken from a product perspective
Settings is an ID-paste form, not a configuration experience. 9 of 12 fields require the user to dig into URLs of 4 separate Google products and Notion, decode cryptic strings, and transcribe them correctly.

connected: true is a lie. The /integrations/status endpoint hardcodes connected: true for all 5 integrations. The sidebar says "Systems Connected" even when Notion databases aren't shared, the Sheet doesn't exist, or the template doc has been deleted.

The Google Docs connector isn't actually used. It's installed but has zero connections. All Docs API calls go through the Drive connector. This is invisible to both the user and any future developer.

Notion database sharing is a hidden prerequisite. The app will silently return zeros for AE/deviation counts if the databases aren't shared with the specific Replit integration (not just "a" Notion integration — the exact one Replit uses). There's no way for Susan to know this is wrong until she opens the report and sees all zeros.

The sponsor call calendar event ID requires a three-step decode process that the Settings page currently explains using developer tooling (a third-party base64 website).
